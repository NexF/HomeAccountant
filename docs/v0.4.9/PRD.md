# v0.4.9 — 金额正负着色：红正绿负动态配色

> **版本：v0.4.9**
> **创建日期：2026-03-03**
> **基于版本：v0.4.8（隐私模式）**
> **状态：规划中**
> **本版本变更：金额格式化函数新增自动正负着色选项，损益表全面适配红正绿负**

---

## 1. 背景

### 1.1 问题描述

当前损益表（`IncomeStatementTable`）中，**收入科目固定红色、费用科目固定绿色**，颜色仅由 `account_type` 决定，不看金额正负。

然而，部分科目金额可能出现「反向值」：
- **投资收益**属于收入科目，但可能因亏损而为**负数** — 此时仍显示为红色，产生语义矛盾
- 反之，某些费用冲销也可能出现正值的退款记录

目前只有「本期损益 `net_income`」一处根据金额正负动态着色，其余账户行均为固定着色。

### 1.2 现有着色模式

| 组件 | 当前着色逻辑 | 问题 |
|------|-------------|------|
| 损益表 — 账户行 | `account_type === 'income'` → 红色 / `'expense'` → 绿色 | **不看正负**，投资亏损仍显示红色 |
| 损益表 — 总收入/总费用 | 固定红/绿 | 同上 |
| 损益表 — 本期损益 | `net_income >= 0` → 红 / `< 0` → 绿 | **已正确** |
| 资产负债表 — 账户行 | `balance > 0` + `account_type` 组合判断 | 已有正负判断 |
| 净资产变动 | `change > 0` → 红 / `< 0` → 绿 | 已正确 |
| 分录卡片 | `impact > 0` → 红 / `< 0` → 绿 | 已正确 |

### 1.3 设计目标

| 目标 | 说明 |
|------|------|
| 统一语义 | 金额正负与颜色一致：**正数红色（A 股涨色）、负数绿色（跌色）、零灰色** |
| 最小改动 | 在 v0.4.8 已统一的 `utils/format.ts` 基础上，扩展颜色能力，组件端改动尽量少 |
| 向后兼容 | 新增选项为 opt-in，不影响不需要着色的场景 |
| 零后端改动 | 纯前端功能 |

## 2. 方案设计

### 2.1 核心思路：在格式化层提供颜色信息

v0.4.8 已将所有金额格式化统一到 `utils/format.ts` 的 4 个函数。本版本在此基础上新增一个**颜色工具函数**，组件端调用后即可获取正确颜色，无需各自写正负判断逻辑。

#### 2.1.1 新增工具函数

```typescript
// utils/format.ts 新增

/**
 * 根据金额正负返回语义颜色
 * @param v 金额数值
 * @param invert 是否反转正负语义（用于费用科目：正数=支出→绿色，负数=退款→红色）
 * @returns 颜色字符串：正数→Colors.asset(红), 负数→Colors.liability(绿), 零→Colors.neutral(灰)
 *          invert=true 时正反互换
 */
export function getAmountColor(v: number, invert?: boolean): string;
```

#### 2.1.2 使用方式

调用方只需一行即可获得正确颜色，`invert` 参数处理费用科目的反向语义：

```tsx
// Before（当前代码）
const balanceColor =
  item.account_type === 'income'
    ? Colors.asset
    : item.account_type === 'expense'
    ? Colors.liability
    : colors.text;

// After（v0.4.9）
// 收入科目：正数=赚钱→红色，负数=亏损→绿色
// 费用科目：正数=花钱→绿色，负数=退款→红色（invert=true）
const balanceColor = getAmountColor(
  item.balance,
  item.account_type === 'expense'
);
```

### 2.2 具体着色规则

#### 2.2.1 金额着色语义

| 金额值 | 颜色 | 常量 | 含义 |
|--------|------|------|------|
| `> 0` | 红色 `#EF4444` | `Colors.asset` | 正向：收入、资产增值、盈利 |
| `< 0` | 绿色 `#10B981` | `Colors.liability` | 负向：亏损、负债、支出 |
| `= 0` | 灰色 `#6B7280` | `Colors.neutral` | 无变化 |

> 遵循中国 A 股涨跌配色习惯：**红涨绿跌**。

#### 2.2.2 损益表改造详情

| 元素 | 当前着色 | 改造后着色 |
|------|---------|-----------|
| 收入科目行金额 | 固定红色 | `getAmountColor(balance)` — 正数红（赚钱）、负数绿（亏损） |
| 费用科目行金额 | 固定绿色 | `getAmountColor(balance, true)` — 正数绿（花钱）、负数红（退款） |
| 摘要卡片 — 总收入 | 固定红色 | `getAmountColor(total_income)` |
| 摘要卡片 — 总费用 | 固定绿色 | `getAmountColor(total_expense, true)` |
| 收入合计行 | 固定红色 | `getAmountColor(收入合计值)` |
| 费用合计行 | 固定绿色 | `getAmountColor(费用合计值, true)` |
| 本期损益 | 已按正负着色 | 改用 `getAmountColor()` 保持一致 |
| 占比条颜色 | 按 type 固定红/绿 | **保持不变** — 占比条表达类别归属，非金额方向 |

#### 2.2.3 交互示例

正常情况（投资收益为正）：

│  费用合计         ¥4,000.00   🟢 │

### 2.3 其他组件改造

除损益表外，以下组件也需要适配正确的正负着色逻辑：

#### 2.3.1 资产负债表（`BalanceSheetTable.tsx`）

| 元素 | 当前着色 | 改造后着色 |
|------|---------|-----------|
| 资产科目行 | `balance > 0` → 红色，`< 0` → 绿色 | `getAmountColor(balance)` — 正数红、负数绿（不变） |
| 负债科目行 | `balance > 0` + `liability` → 绿色 | `getAmountColor(balance, true)` — 正数绿（欠钱）、负数红（超额还款） |
| 权益科目行 | 同资产逻辑 | `getAmountColor(balance)` |
| 本期损益 | `net_income >= 0` → 红 / `< 0` → 绿 | `getAmountColor(net_income)` |
| 对账差异 | `diff > 0` → 红 / `< 0` → 绿 | `getAmountColor(diff)` |
| 总资产/总负债 | 固定红色/绿色 | `getAmountColor(total_asset)` / `getAmountColor(total_liability, true)` |
| 等式中资产/负债 | 固定红色/绿色 | `getAmountColor(total_asset)` / `getAmountColor(total_liability, true)` |

> **关键**：负债科目与费用科目类似，正数表示"欠了钱"（负向），需 `invert=true`。

#### 2.3.2 总览页（`(tabs)/index.tsx`）

| 元素 | 当前着色 | 改造后着色 |
|------|---------|-----------|
| 本月收入金额 | 固定红色 `Colors.asset` | `getAmountColor(month_income)` |
| 本月费用金额 | 固定绿色 `Colors.liability` | `getAmountColor(month_expense, true)` — 费用正数→绿色 |
| 本月结余 | `month_net_income >= 0` → 红 / `< 0` → 绿 | `getAmountColor(month_net_income)` |

#### 2.3.3 净资产卡片（`NetWorthBadge.tsx`）

| 元素 | 当前着色 | 改造后着色 |
|------|---------|-----------|
| 净资产变动 | `change > 0` → 红 / `< 0` → 绿 / `= 0` → 灰 | `getAmountColor(change)` |
| 总资产 | 固定红色 | `getAmountColor(totalAsset)` |
| 总负债 | 固定绿色 | `getAmountColor(totalLiability, true)` — 负债正数→绿色 |

#### 2.3.4 分录卡片（`EntryCard.tsx`）

| 元素 | 当前着色 | 改造后着色 |
|------|---------|-----------|
| `net_worth_impact` | `> 0` → 红 / `< 0` → 绿 / `= 0` → 灰 | `getAmountColor(impact)` |

#### 2.3.5 不变更的组件

| 组件 | 原因 |
|------|------|
| `entry/[id].tsx` — 借贷方金额 | 借方/贷方有独立语义（借=资产色、贷=负债色），不应改为纯正负判断 |
| 占比条 (`PercentBar`) | 表达类别归属而非金额方向，保持按 type 着色 |
| 收入/费用卡片的箭头图标 | `arrow-up`/`arrow-down` 及图标颜色保持固定，表达类别含义 |

## 4. 验收标准

| 编号 | 验收项 | 验收标准 |
|------|--------|---------|
| AC-1 | 损益表收入正数 | 收入科目正数（赚钱）显示红色 |
| AC-2 | 损益表收入负数 | 收入科目负数（如投资亏损）显示绿色 |
| AC-3 | 损益表费用正数 | 费用科目正数（花钱）显示绿色 |
| AC-4 | 损益表费用负数 | 费用科目负数（退款）显示红色 |
| AC-5 | 损益表零值 | 金额为零时显示灰色 |
| AC-6 | 资产负债表资产 | 资产正数红色、负数绿色 |
| AC-7 | 资产负债表负债 | 负债正数绿色（欠钱）、负数红色 |
| AC-8 | 总览本月收入 | 正数红色、负数绿色 |
| AC-9 | 总览本月费用 | 正数绿色（花钱）、负数红色（退款） |
| AC-10 | 总览本月结余 | 正数红色（盈利）、负数绿色（亏损） |
| AC-11 | 净资产变动 | 正数红色、负数绿色、零灰色 |
| AC-12 | 占比条不受影响 | 占比条颜色仍按收入/费用类型固定着色 |
| AC-13 | 隐私模式兼容 | 隐私模式下遮罩文本不受着色影响 |
| AC-14 | 零后端改动 | 纯前端实现，不涉及 API 调用 |

## 5. 约束与风险

| 约束/风险 | 说明 | 缓解措施 |
|----------|------|---------|
| 费用金额正负语义 | 后端返回的费用金额通常为正数（表示支出额），语义上是「减少净资产」 | 费用科目使用 `getAmountColor(v, true)` 反转颜色：正数→绿色（花钱）、负数→红色（退款） |
| 隐私模式下的颜色 | 隐私遮罩时显示颜色可能泄露金额正负信息 | 隐私模式下可统一使用默认文字色，不区分正负 |
| 改动范围小 | 核心改动仅 2 个文件，风险可控 | — |
